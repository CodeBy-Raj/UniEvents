# UniEvents

UniEvents is a React Native mobile app for managing college club events with separate student and admin workflows.

## Resume-ready project description

You can copy this directly into your resume:

**UniEvents — React Native + Appwrite**
- Built a cross-platform event management app for college clubs using **React Native** and **React Navigation**, with dedicated tabs for events, admin, and student flows.
- Implemented **Appwrite-backed CRUD** for event and registration data, including duplicate-registration checks and club-wise event filtering.
- Developed admin and student experiences with secure admin-code access, real-time event listing, pull-to-refresh, registration handling, and in-app feedback via toast notifications.

## Tech stack

React Native, JavaScript, Appwrite, React Navigation, React Native Paper, Lottie animations
